# Отчёт по API — 24 октября 2026

## Что фактически проверено

HTTPS GET официальных страниц документации `docs.csfloat.com`, `docs.skinport.com`,
`market.csgo.com/docs-v2` завершился `CONNECT tunnel failed, response 403` на прокси.
Повтор с повышенными разрешениями среды результат не изменил. Запросы
`https://csfloat.com/api/v1/listings?limit=1&type=buy_now` и
`https://api.skinport.com/v1/items?app_id=730&currency=USD&tradable=1`
тоже отклонены прокси до установления HTTPS-соединения с площадкой.
Исходный прототип также содержал запрос Steam `priceoverview`; он оказался заблокирован.
Этот недокументированный маршрут не используется в приложении.

**Ни один реальный API площадки не подтверждён работающим в этой сессии.**
Нет полученного реального JSON, измеренной текущей квоты, подтверждения коммерческой
лицензии, успешного вывода средств или Telegram-доставки. Ключи и Telegram-токен
в переменных окружения проекта отсутствовали; новые значения не запрашивались в чате.

## Источники для проверки пользователем

- CSFloat: https://docs.csfloat.com/ и https://csfloat.com/terms-of-service
- Skinport: https://docs.skinport.com/ и https://skinport.com/terms-of-service
- Market.CSGO: https://market.csgo.com/docs-v2
- Steam: https://partner.steamgames.com/doc/webapi и https://store.steampowered.com/subscriber_agreement/

Это адреса проверки, а не утверждение, что содержимое этих страниц удалось прочитать.
Перед коммерческим использованием уточните у площадки разрешённый вид применения,
перепубликацию цен, хранение истории и ограничения запросов. Приложение не лицензирует
полученные данные. Утверждение из ZIP «ключи не нужны» не принято как доказательство.

В ZIP заявлены для Skinport кэш 5 минут и 8 запросов за 5 минут. Эти значения не удалось
независимо подтвердить. В MVP один сетевой цикл не чаще 370 секунд на процесс,
CSFloat ограничен 1–10 страницами (по умолчанию 2), пауза между страницами 1,5 с.
Это локальные ограничения реализации, а не гарантия соответствия текущим тарифам/квотам.
429 запускает паузу не меньше Retry-After; 403 не повторяется автоматически и не обходится.

## Как завершить проверку

В облачной среде сохранены добавления доменов в черновик настроек, но сохранение черновика
не меняет работающий прокси. Пользователь должен сохранить настройки среды и опубликовать
обновлённую конфигурацию. На Windows проверьте доступ из собственной разрешённой сети.
Не отключайте TLS, не используйте обход CAPTCHA, подмену cookies или ротацию прокси.

После восстановления доступа перечитайте официальную документацию, подтвердите контракт,
условия и квоты, задайте `API_TERMS_ACCEPTED=true` только при соответствующем разрешении.
Запустите `python -m skin_radar scan --live` и зафиксируйте ответ/количество котировок.
Положительный ответ HTTP ещё не подтверждает выгодность сделки или возможность вывода.
Отдельно проверьте KYC/регион/метод выплат, реальные комиссии и ограничения передачи.

Сейчас bid-адаптеров и истории совершённых продаж нет. Поля для них заложены в модели,
но ни ask, ни медиана, ни последняя продажа не превращаются в bid. При отсутствии
реальных продаж интерфейс показывает неизвестную ликвидность и недостаточную уверенность.
