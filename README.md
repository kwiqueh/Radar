# SKIN RADAR

Локальный сканер кандидатов на межплощадочную маржу CS2 для Python 3.12 / Windows 11.
FastAPI-панель, Telegram-команды, SQLite, Decimal-расчёты и полностью автономный demo-режим.
Покупки, продажи и денежные переводы приложение не выполняет.

**Версия 0.2:** панель умеет загружать настоящий публичный RUB-каталог Market.CSGO.
Проверены реальный ответ JSON, десятки тысяч позиций и поиск через браузер. Это справочные
цены, не bids: они не используются как доказательство арбитража. CSFloat реально отвечает
403 с требованием авторизации без ключа; Skinport отвечает 403 со страницей защиты.
Доступ с вашим ключом и возможность денежного вывода ещё не проверены. Steam выключен.
Подробности: [отчёт API](docs/API_REPORT.md), [аудит архива](docs/ARCHIVE_AUDIT.md),
[ограничения и план развития](docs/LIMITATIONS.md).
Результаты проверок и их границы: [тесты и браузерные проверки](docs/VALIDATION.md).

## Обновление и подключение через панель

В 0.2.1 сводка показывает ближайший необходимый шаг. Если чтение API выключено,
включите его в блоке подключения после проверки условий. Для начала можно выбрать только
Market.CSGO: его RUB-каталог не требует ввода курсов, комиссий или допуска неизвестного hold.
Настройки прибыли понадобятся после получения торговых котировок двух площадок.

Если у вас уже работает demo, остановите старый процесс (Ctrl+C) и обновите исходники
из ветки или нового ZIP. Сохраните свои `.env`, `fees.local.json` и `*.db`.
Новый ZIP их не содержит. Не запускайте две версии одновременно на одном порту.

Из папки проекта в PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-SkinRadar.ps1
```

Политика исполнения меняется только для этого запуска PowerShell, не для всей системы.
Скрипт создаёт `.venv`, устанавливает зависимости при изменении lockfile/pyproject и запускает
панель. Системный Python 3.12 с командой `py` должен быть установлен. Ручной способ ниже
также работает. Сам PowerShell-скрипт подготовлен, но не исполнен под Windows в этой сессии.

В панели откройте «Настройка реальных данных», выберите «Реальные данные» и Market.CSGO,
проверьте условия выбранных API, подтвердите своё право на чтение и нажмите
«Сохранить и проверить источники». Настройки применяются без перезапуска. Каталог появляется
в «Котировки площадок»; поиск, фильтр цены и страницы работают отдельно от прибыльных кандидатов.
Для RUB-каталога курс USD и тарифы не требуются. Для расчёта прибыли они обязательны.

Свой API-ключ CSFloat можно ввести в поле панели: пустое поле сохраняет существующий ключ.
Значение никогда не возвращается сервером в браузер; показывается лишь факт наличия.
Ключ сохраняется **в открытом виде только на вашем ПК** в `settings.local.json` (не в Git).
На Unix новый файл имеет режим 0600, на Windows действуют права каталога вашего аккаунта.
Не пересылайте этот файл и не размещайте папку проекта в публичном доступе. Приоритет:
настройки панели в `settings.local.json` выше `.env`; режим `--demo`/`--live` переопределяет
сохранённый режим при старте. Поэтому для постоянного выбора используйте запуск без `--demo`.
После 401/403 запросы к отказавшему провайдеру останавливаются до изменения ключа CSFloat
либо перезапуска после исправления сетевого доступа. Автоматические попытки обхода не выполняются.

Профили комиссий редактируются в панели. Отметьте проверку курса только после ввода
фактических значений. Нулевые тарифы в пустом профиле не считаются подтверждёнными.
Неизвестные сроки передачи и ликвидность по-прежнему выделяются или исключаются фильтрами.

## Windows 11 / PowerShell

Используйте отдельный репозиторий `kwiqueh/Radar`, ветку `feature/skin-radar-mvp`.
`kwiqueh/mtsss` не используется.

```powershell
git clone --branch feature/skin-radar-mvp https://github.com/kwiqueh/Radar.git
cd Radar
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe -m pip install --no-deps -e .
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m skin_radar scan --demo
.\.venv\Scripts\python.exe -m skin_radar serve --demo
```

Откройте локальную панель в браузере: адрес хоста `127.0.0.1`, порт `8000`.
Она автоматически сканирует при старте и затем каждые 370 секунд. Кнопка «Сканировать»
в пределах этого интервала пересчитывает кэш, не обходит лимит запросов к площадкам.
Приложение отклоняет публичный bind, чужой Host и изменения из посторонних браузерных origin.
Это панель для одного локального пользователя; интернет-публикация не поддерживается.

Команда `run` включает панель и настроенный Telegram-бот в одном процессе, `bot` — только
бот с периодическим сканированием, `scan` — один скан. Остановка — Ctrl+C.
Не запускайте одновременно несколько экземпляров с одним Telegram-токеном или одной БД.

Demo не требует ключей, использует три синтетические котировки и никогда не посылает
автоматические уведомления. В нём условный кандидат: покупка 1 200 ₽, ask продажи 1 700 ₽,
вложения с резервом расходов 1 260 ₽, чистый расчётный остаток 191,12 ₽, ROI 15,17%.
Это пример вычислений, а не реальная сделка. Ручная `/top` в настроенном боте показывает
явную метку DEMO.

## Ручная настройка через .env

Этот способ предназначен для первого запуска без сохранённых настроек панели.
Если уже существует `settings.local.json`, соответствующие значения из него имеют приоритет.

1. Прочитайте [отчёт API](docs/API_REPORT.md) и текущие официальные документы площадок.
   Убедитесь, что ваш доступ и способ использования разрешены. В live по умолчанию запросы
   выключены: `SKIN_RADAR_API_TERMS_ACCEPTED=false`.
2. Откройте `.env` через `notepad .env`. Установите `SKIN_RADAR_MODE=live`,
   `SKIN_RADAR_API_TERMS_ACCEPTED=true`. При необходимости заполните собственный
   `SKIN_RADAR_CSFLOAT_API_KEY`. Ключ передаётся в Authorization только CSFloat.
3. Задайте **фактические** `SKIN_RADAR_USD_RUB` и `SKIN_RADAR_EUR_RUB`, учитывающие ваши
   затраты на конвертацию. Укажите `SKIN_RADAR_FX_VERIFIED_AT` в ISO 8601 с поясом,
   например своим текущим временем вида `2026-10-24T16:00:00+03:00`. Не копируйте эту дату
   как актуальную. Через 24 часа расчёт live-сигналов прекращается до обновления курса.
4. `Copy-Item fees.example.json fees.local.json`. Все числа в примере — иллюстрации.
   Для каждой площадки заполните процентные и фиксированные комиссии пополнения,
   покупки, продажи, вывода и минимум вывода в рублёвом эквиваленте. Проверьте KYC,
   регион и конкретный способ получения денег. Только после этого задайте
   `verified=true` и `cashout_available=true` в соответствующем профиле.
5. Запустите `.\.venv\Scripts\python.exe -m skin_radar scan --live`.
   Посмотрите количество реально загруженных котировок и `/status`.
   Недоступность всех API даёт ненулевой код выхода 2. Ошибка API не заменяется demo-данными.
6. Запустите `.\.venv\Scripts\python.exe -m skin_radar run --live`.

По умолчанию неизвестный срок передачи исключает кандидата. Текущие адаптеры не могут
надёжно определить этот срок: не выводят его из несвязанных полей API. Для изучения
потенциальной маржи можно явно задать `SKIN_RADAR_ALLOW_UNKNOWN_HOLD=true` в `.env`
или фильтрах. Такие сигналы имеют неизвестный hold и предупреждение; лимит удержания
для них проверить невозможно. При `false` неизвестность никогда не считается нулём.

Публичные котировки Skinport являются агрегатами по базовому `market_hash_name`,
а не индивидуальными объявлениями. Ссылка ведёт на рынок предмета; индивидуальная
ссылка CSFloat предоставляется при наличии ID объявления. Оба источника сейчас дают ask,
а не исполнимые bids. Поэтому реальные результаты могут быть только кандидатами,
даже если все комиссии подтверждены. Поля исторических продаж не выдумываются.

## Фильтры и вычисления

Панель и `/filters` позволяют менять бюджет 1 000–5 000 ₽, резерв, максимум цены предмета,
минимум прибыли, ROI, ликвидность, возраст котировки, предел hold, список площадок и
исключённых точных имён предметов. Изменения проверяются вместе и сохраняются в SQLite.
Бюджет должен покрывать **все** вложения плюс отдельно выделенный денежный резерв.

```text
вложения = цена покупки + комиссия покупки + пополнение
          + резерв непредвиденных расходов + фиксированные расходы
поступление = цена продажи - комиссия продавца
чистый вывод = поступление - процент/фиксированная комиссия вывода
прибыль = чистый вывод - вложения
ROI = прибыль / вложения × 100%
```

Денежные расчёты используют Decimal, округление HALF_UP до копейки — при выдаче результата.
Конвертация выполняется до расчёта затрат по явно указанным рублёвым курсам.
Минимум вывода и доступность cashout проверяются до включения результата.
Расчёт относится к одному предмету: это не оптимизатор портфеля и не способ обойти минимум
вывода суммированием будущих неопределённых продаж.

`market_hash_name`, exterior, StatTrak и Souvenir должны совпадать. Если float, pattern
или наклейки известны у обоих источников и различаются, пара исключается. Если атрибут
известен только с одной стороны, возможна лишь оценка базовой разновидности с явным
предупреждением: премии этих особенностей не подтверждены.

Количество объявлений не считается ликвидностью. При отсутствии реальных продаж
ликвидность обозначается `unknown`, уверенность — `insufficient_data`; такие результаты
можно скрыть через `allow_unknown_liquidity=false`. Нулевая известная ликвидность и
неизвестная ликвидность различаются. Ask-спред не получает подтверждённую уверенность.

## Telegram

Создайте собственного бота в BotFather. Заполните локально
`SKIN_RADAR_TELEGRAM_BOT_TOKEN` и `SKIN_RADAR_TELEGRAM_CHAT_ID`, предварительно начав диалог
с ботом. Команды принимаются **только** из настроенного chat ID. Не передавайте токен в чат
разработчику. Steam-пароли, Guard-коды и cookies не нужны.

Команды: `/start`, `/scan`, `/top`, `/filters`, `/stats`, `/status`, `/help`.
Пример изменения: `/filters min_profit_rub=200`. Бюджет, резерв и максимум цены удобнее
обновлять одним набором в панели, если они зависят друг от друга.

Автоматическая рассылка в live — до пяти новых кандидатов за скан. Отпечаток пары источников
и объявления уникален в SQLite, сохраняется после перезапуска. При неопределённом исходе
сетевой отправки повтор подавляется, а статус уведомления — `uncertain`: так уменьшается
риск дубликатов. Это сознательный выбор в пользу at-most-once, возможен пропуск уведомления.
API-токены и полный URL Telegram не выводятся в журнал приложения.

Истории demo и live физически разделены: `skin_radar.demo.db` и `skin_radar.live.db`.
История ограничена последними 100 000 наблюдений; повтор одной котировки не создаёт новую
точку без изменения времени источника/оценки. Это ограничение хранения, не полная история рынка.
Живые процессы не сохраняются между перезагрузками. Файлы `.env`, `fees.local.json`, БД
и `.venv` исключены из Git, как и `settings.local.json`.

## Разработка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m ruff format --check .
```

`skin_radar/providers/` — чтение и нормализация API; `core/` — сопоставление, прибыль,
качество; `storage/` — SQLite; `alerts/` и `bot.py` — Telegram; `dashboard/` — панель;
`tests/` — расчёты, ограничения, ошибки, API mock и функциональный тест панели.

HTTP ограничивает параллелизм, повторяет временные сетевые ошибки и 5xx до трёх попыток,
не повторяет 401/403 и соблюдает Retry-After для 429 через cooldown. Проверка TLS включена.
Встроенные лимиты консервативны, но не являются заявлением о текущих квотах площадок.
При иной квоте используйте более длинный интервал и меньше страниц, не обходите блокировку.

Тесты полностью автономны и не подтверждают коммерческие условия, реальный вывод денег
или доступ API. Windows-команды подготовлены для Python 3.12; выполнение в этой среде
проверяется под Linux. Скриншоты в `docs/screenshots/` относятся только к demo.
